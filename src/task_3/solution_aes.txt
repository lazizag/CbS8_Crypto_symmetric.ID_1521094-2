Флаг: S21{good_job!1!}
Режим работы: ECB

Подробное пошаговое решение:

1. Анализ исходного кода

В файле 4es.py используется AES в режиме CBC:

    cbc = AES.new(key, AES.MODE_CBC, iv)
    ct1 = cbc.encrypt(plaintext)

Ключ создаётся так:

    key = b'Super_Secret_' + os.urandom(3)

Строка b'Super_Secret_' имеет длину 13 байт. AES-128 требует ключ длиной 16 байт, поэтому последние 3 байта ключа неизвестны и генерируются случайно:

    полный ключ = b'Super_Secret_' + 3 неизвестных байта

Значит, нужно перебрать только 3 байта ключа:

    256^3 = 16 777 216 вариантов

Это реально перебрать обычным Python-скриптом.

2. Разделение ciphertext на блоки

Результат работы программы:

    dd95b1d1373f97307b1943a00bd9a09fc9568802187663ff93cadfedd688b644

AES работает блоками по 16 байт. В hex один байт занимает 2 символа, значит один AES-блок занимает 32 hex-символа.

Делим ciphertext на два блока:

    C1 = dd95b1d1373f97307b1943a00bd9a09f
    C2 = c9568802187663ff93cadfedd688b644

3. Почему IV не мешает восстановить второй блок

В CBC расшифрование работает по формуле:

    P1 = D_K(C1) XOR IV
    P2 = D_K(C2) XOR C1

IV нужен только для восстановления первого блока P1.

Для второго блока IV уже не нужен, потому что второй plaintext-блок получается через XOR с предыдущим ciphertext-блоком C1.

Поэтому можно расшифровать C2 обычной AES-расшифровкой одного блока, то есть через ECB, а затем сделать XOR с C1:

    P2 = AES_ECB_decrypt(C2) XOR C1

Именно поэтому для решения понадобился режим ECB, хотя в исходной программе использовался CBC.

4. Перебор неизвестных байтов ключа

Так как известны первые 13 байт ключа, перебираем последние 3 байта.
Для каждого варианта ключа:

    1) создаём AES в режиме ECB;
    2) расшифровываем второй блок C2;
    3) делаем XOR результата с первым блоком C1;
    4) проверяем, получился ли читаемый текст/флаг.

Скрипт для восстановления:

    from Crypto.Cipher import AES

    def xor(a, b):
        return bytes(x ^ y for x, y in zip(a, b))

    ct = bytes.fromhex("dd95b1d1373f97307b1943a00bd9a09fc9568802187663ff93cadfedd688b644")

    c1 = ct[:16]
    c2 = ct[16:32]

    prefix = b"Super_Secret_"

    for i in range(256 ** 3):
        suffix = i.to_bytes(3, "big")
        key = prefix + suffix

        aes = AES.new(key, AES.MODE_ECB)
        p2 = xor(aes.decrypt(c2), c1)

        if b"S21{" in p2:
            print("key =", key)
            print("plaintext block 2 =", p2)
            break

5. Полученный результат

После перебора получается второй блок plaintext:

    S21{good_job!1!}

Его длина ровно 16 байт, поэтому он полностью занимает один AES-блок.

Итог:

    изначальная строка plaintext содержит флаг: S21{good_job!1!}
    режим, который понадобился для расшифровки второго блока: ECB

Ответ:

    Флаг: S21{good_job!1!}
    Режим работы: ECB
